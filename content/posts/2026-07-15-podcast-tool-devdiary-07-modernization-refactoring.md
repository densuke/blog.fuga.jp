## 1,401行のモノリス

第1回の最後に書いた「295行、ぜんぶ入りの `main.py`」の話を覚えているだろうか。立ち上げ期の勢いで一枚岩に詰め込むことは正しい選択だと書いた。その正しい選択は、9月末に清算を迎えた。

`core/ffmpeg_runner.py` の追加が、このリファクタリングの核心だった。それまでコードベースのあちこちに散っていた `subprocess` 経由のFFmpeg呼び出しを、`FFmpegRunner` クラスに一元化する。エラーハンドリング、ログ出力、タイムアウト処理をここに集約することで、個々の呼び出し元がFFmpegの詳細を知らなくて済むようになった。

```python
class FFmpegRunner:
    """FFmpeg/ffprobe実行の統一インターフェース"""

    def __init__(self, ffmpeg_cmd: str = "ffmpeg", ffprobe_cmd: str = "ffprobe"):
        ...

    def run_ffmpeg(self, args: List[str], timeout: int = 300, ...) -> subprocess.CompletedProcess:
        ...
```

午前6時27分、リファクタリングブランチをマージした（`e08f16e`）。一夜かけた解体の第一幕が終わった。

## movie-mix-util との決別

もう一つ、片付けなければならない宿題があった。外部ライブラリ `movie-mix-util` への依存だ。

この依存は動画処理の初期から引きずってきたもので、FFmpegを直接操作するコードと混在する形になっていた。9月27日、仕様を整理してから一気に進めた。

20分で仕上げた。外部ライブラリへの依存が消え、FFmpegRunner に統一された。

`core/`・`models/`・`audio/`・`video/`・`utils/` という5つのパッケージが生まれた。第1回の295行単一ファイルから数えると、ここまでの変化は大きい。

同時に `ruff`・`mypy`・`pre-commit` を `pyproject.toml` に追加した。`ruff` の設定は `lint.select = ["E", "F", "W", "ANN"]`、`mypy` は `disallow_untyped_defs = true`。コードスタイルの統一と型安全を担保する仕組みを、ここで初めて正式に導入した。
